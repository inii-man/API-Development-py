Bayangkan dua browser tab atau dua klien (Klien A dan Klien B) sama-sama membaca task saat versi bernilai 1. Keduanya berniat mengubah status task. Siapa yang berhasil, dan apa yang terjadi pada yang terlambat?

Status: Menunggu eksekusi...

🖥️ Klien B (User Alice - Tab 2)

Juga membaca task saat versi = 1. Terlambat mengirim request perubahan.

Status: Menunggu eksekusi...

Penjelasan Arsitektur:

Klien A berhasil mengupdate database karena versi masih 1. Query menaikkan versi menjadi 2. Ketika Klien B mengirim request dengan versi 1, kondisi WHERE version = 1 tidak lagi cocok. Server mendeteksi cur.rowcount == 0 dan mengembalikan 409 VERSION_CONFLICT. Klien B diwajibkan membaca ulang state terbaru sebelum memutuskan perubahan berikutnya.
